# Changelog

## 0.1.0

First independent public release of the DSH ZenTao Ledger.

- Read Bug lists, details, history and compatible product requirements; filter loaded records and group active Bugs by assignee.
- Save local drafts and selected image/video media with expected/actual roles, then review before an explicit submission.
- Preserve identity checks, association checks, bounded media validation, readback and uncertain-write protection.
- Configure your own ZenTao origin, product and project; isolate public-plugin credentials, browser caches and drafts from private local installations.
- Use compatible token exchange or an existing authenticated session cookie. Unsupported REST upload authorization remains an explicit limitation.
- Make AI description/image assistance optional with an explicitly configured DSH provider/model.
- Include synthetic fixtures, CI, package validation, bilingual documentation and public demo screenshots.

Deployment compatibility is limited to the documented classic JSON/web-form contracts. Synthetic tests and demonstration screenshots do not establish compatibility with every ZenTao version or a production acceptance result.
